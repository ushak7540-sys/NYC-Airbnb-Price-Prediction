# NYC Airbnb Price Prediction

Linear Regression model to predict nightly Airbnb prices in New York City.

- Dataset: Kaggle "New York City Airbnb Open Data" (AB_NYC_2019)
- Steps: EDA, cleaning, outlier removal, one-hot encoding, train/test split, model training, residual analysis
- Results: R² = 0.451, MAE = $37.45, RMSE = $50.92
- Tools: Python, pandas, scikit-learn, matplotlib, seaborn

Files:
- NYC_Airbnb_Linear_Regression.ipynb: full notebook
- NYC_Airbnb_Price_Prediction_Report.pdf: 1-page summary
